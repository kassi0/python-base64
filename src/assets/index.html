POST /api/encode

Codifica texto ou arquivo em Base64.

curl -X POST http://localhost:8080/api/encode \ -H "Content-Type: application/json" \ -d '{"data": "Olá Rust!", "urlsafe": false}'
POST /api/decode

Decodifica string (com suporte a data URLs e padding automático).

curl -X POST http://localhost:8080/api/decode \ -H "Content-Type: application/json" \ -d '{"data": "T2zDoSBSdXN0IQ=="}'
POST /api/auto-decode

Detecta e decodifica Base64 em YAML (type: Opaque), JSON ou texto livre.

curl -X POST http://localhost:8080/api/auto-decode \ -H "Content-Type: text/plain" \ --data-binary @secret.yaml
POST /api/diff

Compara dois textos e retorna diferenças linha a linha.

curl -X POST http://localhost:8080/api/diff \ -H "Content-Type: application/json" \ -d '{"original": "A", "modified": "B"}'
